## Guidelines for Generating Trajectories

1. **Be Realistic**: Include realistic tool outputs with confidence scores, bounding boxes, timestamps
2. **Handle Errors**: Sometimes tools may fail or return partial results - show how to handle this
3. **Chain Outputs**: Show how output from one tool feeds into the next
4. **Explain Reasoning**: Use <thinking> blocks to explain your decision-making
5. **Provide Final Summary**: Always conclude with a clear summary of results
6. **Include Edge Cases**: Show handling of:
   - Low confidence results
   - Missing or partial data
   - Multiple matches requiring disambiguation
   - Tools that need to be re-run with different parameters
